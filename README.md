# Nailoong Widget for Waveshare ESP32-S3-Touch-LCD-1.46

An interactive Nailoong (奶龙) widget for the Waveshare ESP32-S3-Touch-LCD-1.46 board.

## Description

Touch the screen to make Nailoong laugh out LOUD! This project demonstrates a simple interactive touch UI using LVGL on ESP32-S3 hardware.

## Features

- Touchscreen interaction
- Nailoong laugh response on click
- Built for Waveshare ESP32-S3-Touch-LCD-1.46

## Usage

1. Flash the project to your ESP32-S3-Touch-LCD-1.46 board.
2. Tap the touchscreen.
3. Enjoy Nailoong laughing loudly.

## Library version requirements

- `esp32` by Espressif Systems @ `3.0.2`
- `lvgl` @ `8.3.10`
- `ESP32-audioI2S-master` @ `2.0.0`
